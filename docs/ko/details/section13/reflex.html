아키텍처: CNN이 RGB-D 영상에서 상자를 찾고, 기하 계층이 특징 8개를 추출한다. GRU는 이 특징과 카메라 ego-motion 이력으로 8차원 동역학 latent를 예측한다. 고정된 action decoder는 이 latent와 로봇 상태로 전신을 제어한다.

핵심 방법론: 1단계는 PPO로 상태 기반 포획 policy를 학습한다. 2단계는 행동 일치, DAgger, encoder·decoder 공동 PPO로 지연된 상자 관측에서 동역학 latent를 학습한다. 3단계는 제어기를 고정하고 자기중심 RGB-D 이력에서 이 latent를 예측하도록 학습한다.

로봇 / 과제: 29-DoF Unitree G1이 사람이 던진 상자를 팔뚝과 몸통으로 받고, 넘어지지 않고 유지한다. 후속 시연은 SONIC을 이용해 상자를 운반하고 사람에게 전달한다.

주요 contribution:

  • RMA 방식의 고정 decoder·latent 회귀를 움직이는 humanoid 카메라로 관측하는 빠른 물체에 확장한다.
  • 제어, 동역학 추론, 시각 학습을 분리하고 각 단계에 직접 감독을 제공한다.
  • 외부 상자 측정 없이 온보드 RGB-D로 실제 G1의 포획 성공률을 제시한다.

종합 점수: 7.4/10.

한계점:

  • 동역학 latent가 상자 크기를 보존하지 않는다. 작은 상자와 큰 상자는 접촉해도 유지에 자주 실패한다.
  • 시각 학습은 3.0–3.5 m 투척을 사용한다. 더 멀고 빠른 투척에서 성능이 낮아진다.
  • 실제 평가는 조건당 20회이다. 95% Wilson 구간은 최대 약 ±20 percentage points에 이른다.
  • 포획 성공이 안정된 자세를 뜻하지는 않는다. 시각 제어기별 torso excursion 편차가 크다.
  • 전체 후속 작업 과정은 20회 중 25%만 성공한다.

데이터셋 / 데이터 수집

  • 제어 학습: 시뮬레이션 상태 기반 PPO 후 행동 정답을 이용한 데이터 집계와 latent 제어기 PPO를 수행한다.

  • 평가 데이터: 초기화 비교는 제어기 6개에 각각 held-out 투척 640회를 사용한다. 실제 G1 평가는 조건당 20회이다.
