# 10.12 HALO

  • 全称： HALO: Human-Aligned Data Collection for WhoLe-body MObile Manipulation
  • 作者： Shuai Yang, Fangyi Xu, Yishu Shen, Kecheng Zheng, Yinghao Xu (HKUST / Robbyant)
  • 发表venue/年份： arXiv预印本，2026年11月
  • arXiv： 2611.16439v1
  • 输入模态： 拖动示教与低阻力被动平台上的自然移动
  • 目标手： 重新设计的双臂夹爪
  • 力反馈： 拖动示教中的直接物理反馈
  • 成本： —

核心方法/设计

操作者直接引导机器人末端执行器，并移动被动平台来示教双臂操作。采集时移除动力底盘。平台保持与部署所用AgileX Tracer AGV 2差速底盘相同的非完整运动约束。

CaRE-Ego、SAM2和DiffuEraser用于分割、跟踪并移除记录图像中的示教者双手。底盘速度标定与响应延迟校正将平台运动对齐到部署指令。系统使用处理后的示教对π0.5策略进行fine-tuning，并采用异步实时动作分块（RTC）执行。

主要贡献

  • 将直接操作反馈与操作者自然移动结合，用于采集全身示教。
  • 处理图像与底盘动作，减少采集和自主部署之间的差异。
  • 与Mobile ALOHA及VR遥操作比较采集效率和学习所得策略。

定量结果

每项任务的采集限时1小时，包括场景重置和物体准备。采集比较由一名对各参评接口均无使用经验的操作者完成。

任务 / 设置 指标 结果 条件

AI研究评估

三位AI评估者的平均分，采用10分制。

维度 分数 理由
重要性 8.0 针对移动与双臂协调示教的采集问题。已评估任务和平台之外的收益仍不确定。
增量贡献 7.0 用直接示教和被动平台替代空间分离的主从控制。策略和视觉处理采用已有方法。
方法质量 7.7 匹配运动约束并校正视觉及控制差异。底盘标定的独立效果尚未得到验证。
有效性 6.7 策略结果和手部移除ablation支持实用性。Zip-Tie Fastening在10 trials中的成功率仅为30.0%。
问题缺口支撑 7.0 相同采集条件的比较和视觉ablation支持对齐效果。仅一名操作者限制了跨用户证据。

综合评分： 7.2/10。

局限性/不足

  • 采集效率比较仅涉及一名操作者，未验证跨操作者表现。
  • Zip-Tie Fastening在10 trials中的成功率仅为30.0%。Sub-millimeter精度是任务要求，并非单独测得的精度结果。
  • 硬件评估限于一种差速底盘及运动约束匹配的采集平台。
  • Push Chair采集时目标桌子固定。主动感知属于未来工作。

数据质量影响

手部移除减少示教与自主执行之间的视觉差异。底盘标定和时间对齐处理被动采集与动力底盘部署之间的差异。Push Chair的ablation支持手部移除，但底盘标定的独立效果尚未得到验证。
