# 9.10 BiGym 2.0

  • 全称： BiGym 2.0: Benchmarking Learned and Agent-Developed Policies for Humanoid Household Manipulation
  • 作者： Zexi Zhang, Zecheng Zhu, Zidong Chen, Zulkhuu Tuya, Stephen James
  • 发表venue/年份： — / 2026（arXiv 2610.07594v2）
  • 仿真平台： MuJoCo
  • 灵巧手支持： 配备两个Dex1平行夹爪的Unitree G1
  • 任务： 到达目标、桌面、洗碗机和厨房台面场景中的20个家务任务
  • 演示： 每任务60个成功的人类VR演示；共1,200个回合
  • 评估： 在9个代表任务上比较VLA微调、模仿学习、演示驱动RL和编码智能体程序的成功率

核心方法/设计

BiGym 2.0将BiGym改造为面向Unitree G1的家务操作基准。人类VR演示与策略评估使用同一个固定的GR00T-WBC行走和平衡控制器。策略接收三个机载RGB相机的图像与机器人本体感觉信息。它们通过统一接口发送手臂、夹爪和身体指令。评估重置时恢复仿真器与控制器状态。

主要贡献

  • 为G1工作空间和行走动力学适配20个家务任务
  • 提供包含同步相机图像和全身执行记录的人类VR演示
  • 为学习策略和编码智能体开发的程序提供统一执行接口
  • 通过恢复控制器状态支持可重复评估

局限性/不足

  • 所有评估均在仿真中进行，每个机器人使用一个固定全身控制器。未评估真实机器人部署及其他控制器。
  • 编码智能体每任务接收一个演示；学习策略使用60个演示训练。
  • VLA微调每任务仅进行一次训练。其他学习方法进行三次训练。
  • 未评估已验证程序和技能的跨任务复用。
  • 跨工作空间的积木堆叠仍是开放难题。多物体搬运对模仿学习、演示驱动RL和编码智能体程序仍然困难。
