Towards Agentic Robots: Model, Data, Environment, and Harness

Full title: Towards Agentic Robots: Model, Data, Environment, and Harness

Authors: Chonghan Qin et al.

Venue/Year: — / 2026

arXiv: 2610.20442v1

Architecture: Literature survey. Model, Data, Environment, and Harness organize the functions of existing robot systems.

Key methodology: Reviews the development from robot policies through VLA models, world models, and world-action models to agentic robots. Defines 17 functional categories across four domains. Categories can overlap, so a study can appear in more than one category. Compares agent decisions, tools, robot executors, and feedback in representative systems.

Robot / Tasks: Survey of physical and simulated robot systems; task planning, execution monitoring, failure recovery, and capability development.

Main contributions:

  • Defines agentic robots through goal-directed planning, capability coordination, and execution feedback.
  • Connects model learning, data collection and refinement, environment construction, and runtime coordination in one taxonomy.
  • Extends the execution and integration focus of prior surveys, including PAPAV, to data, environments, and capability development.

Quantitative results: —. A quantitative evaluation of the taxonomy is not reported in the source excerpt.
