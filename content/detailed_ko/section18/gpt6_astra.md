### Has GPT-6-Astra Achieved Embodied Intelligence?

**전체 제목:** Has GPT-6-Astra Achieved Embodied Intelligence?

**저자:** SenseNova Joint Research Team; Zhongang Cai 외

**학회/연도:** — / 2026

**arXiv:** [2610.22471v1](https://arxiv.org/abs/2610.22471v1)

**아키텍처:** GPT-6-Astra는 가중치를 고정한 상위 System 2 추론기로 작동함. 협업 실험에서는 RoboDojo로 fine-tuning한 π0.5가 하위 System 1 VLA 제어기로 작동함. 모델 내부 구조: —.

**핵심 방법론:** 학습 시연에서 과제별 메모와 재사용 코드를 포함한 ICL 지식 패키지를 만들고 테스트 전에 동결함. 테스트 에피소드는 별도 세션을 사용하며 에피소드 간 정보를 전달하지 않음. 표준(1×)·확장(10×) 행동 예산에서 제어 인터페이스와 성공 기준을 고정함. 확장 시에는 초기화 없이 같은 에피소드를 이어감. RoboDojo ablation에서 제어기 협업, 행동 표현, 행동 묶음을 비교함. 폐루프 협업에서는 GPT-6-Astra가 제안된 말단장치 행동을 수락·수정·거부함. 실제 로봇 실험에서는 시연 없이 사람이 작성한 문맥과 실제 경과 시간 예산을 사용함.

**로봇 / 과제:** Benchmark 12개가 테이블탑 조작, humanoid 이동·조작, 가사 활동, 이동, dexterous hand를 다룸. 실제 로봇 구성 8개는 단일·양팔, gripper, dexterous hand, 바퀴형 이동 조작 로봇, humanoid를 포함함.

**주요 기여:**

- 고정된 범용 모델을 시연 기반 ICL과 표준·확장 행동 예산으로 평가함.
- 직접 제어와 폐루프 VLA 협업의 성공률·비용을 비교함.
- 실제 로봇의 운용 제약을 확인하고, 동일 도메인 시연 없이 추론 중에도 시간이 흐르는 benchmark 시제품을 제안함.

**정량적 결과:**

| Benchmark / 과제 | 지표 | 값 | 조건 |
|---|---|---|---|
| SIMPLE | 성공률 | 90.8% | 과제별 ICL; zero-shot: 70.8%; 공통 과제 4개, 표준 예산 |
| RoboDojo | 범주별 성공률의 비가중 평균 | 54.17% | ICL + 폐루프 VLA; ICL 직접 제어: 29.67%; 통제된 제어 시스템 ablation |
| 실제 강체 집기·놓기 | 성공 시행 수 | 17/18 | 사람이 작성한 문맥을 사용하는 zero-shot 실제 로봇 평가 |
| 실제 플러그 삽입 | 성공 시행 수 | 0/11 | 로봇 플랫폼 3개에서 평가 |

**AI 연구 평가:** 세 검토자의 평균 점수, 10점 척도.

| 항목 | 점수 /10 | 근거 |
|---|---|---|
| 중요도 | 8.0 | 여러 로봇 유형의 결과로 신뢰성·효율의 병목을 확인함. 경제적인 실제 운용 가능성은 불확실함. |
| 추가 기여 | 7.0 | ICL 지식 패키지와 폐루프 VLA 검토로 RoboRSI 기반 직접 제어를 확장함. 핵심 contribution은 평가와 시스템 통합에 있음. |
| 방법 품질 | 8.0 | 지식 패키지를 동결해 준비와 테스트를 분리함. 같은 에피소드의 확장으로 복구를 평가하지만 패키지 구성요소의 효과는 분리하지 못함. |

**종합 점수:** 7.4/10.

**한계점:**

- 지식 패키지는 원래 과제에 의존하며 시연 분포 밖 전이가 약함.
- 높은 토큰 비용과 긴 실행 시간이 실시간 운용을 제한함.
- 물리적 완료 확인, 비가역 실패 복구, 장기 과제의 진행 상태 보존이 불안정함.
- 실제 로봇 실험은 플랫폼별로 사람이 작성한 문맥을 사용하고 일부 성공 기준도 달라 직접 비교가 제한됨.
- 지식 패키지 구성요소별 contribution을 분리하는 평가는 없음.

## 데이터셋 / 데이터 수집

- **훈련 데이터:** Benchmark 학습 시연으로 동결 ICL 지식 패키지를 준비하며 GPT-6-Astra 가중치는 고정함. System 1 π0.5 제어기는 RoboDojo로 fine-tuning함.
- **평가 데이터:** SIMPLE과 RoboDojo를 포함한 benchmark 12개 및 실제 로봇 구성 8개의 시행. 실제 로봇 실험에서는 시연에서 만든 지식 패키지를 사용하지 않음.
